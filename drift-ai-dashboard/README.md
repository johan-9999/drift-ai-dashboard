# drift-ai-dashboard

The Drift AI prototype application. See the [repository README](../README.md) for the full product overview.

## Development

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build -> dist/
npm run preview  # serve the production build
```

Built with React 19, Vite, Recharts, and the Anthropic TypeScript SDK.
